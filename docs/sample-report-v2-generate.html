Lexical overlap

A question that copies its source passage's wording can be answered by keyword search alone, which makes a retriever look better than it is. Each question is rewritten once; if more than 50% of its content words still appear in the passage, it gets one more rewrite and is then rejected as too_lexical. Median overlap this run: 0.50.
